# Quiz Builder Syria — منشئ الاختبارات

A client-only, Arabic (RTL) printable exam generator for Syrian teachers who are not technical.

A teacher pastes an exam JSON file (written by their own AI chatbot), uploads images, picks a template, and prints or saves a two-column A4 exam using the browser print dialog. No backend, no accounts, no data leaves the browser.

## Live site

GitHub Pages: https://mohammedxmoussa.github.io/quiz-builder-syria/

- App: `index.html`
- AI guide for teachers' chatbots: `ai/quiz-creator-ai.md` — live at https://mohammedxmoussa.github.io/quiz-builder-syria/ai/quiz-creator-ai.md
- Example exam JSON: `ai/example-quiz.json`

## Deployment

Pushing to the `main` branch auto-deploys this site to GitHub Pages via `.github/workflows/pages.yml`.
